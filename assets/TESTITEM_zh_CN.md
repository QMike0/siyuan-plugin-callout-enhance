> *注意嵌套块中的表现；“callout正文区域为空且仅一个空行”简称“空callout”*

## 1. 标题编辑区域
- 标题区域单击：光标定位正确，且不会误触发类型菜单或折叠按钮
- 标题区域回车：
  - callout 展开时：在正文区域首行新增块
  - callout 折叠时：在 callout 块下方新增块，不展开 callout
- 标题区域输入：
  - 中文输入法下输入正常
  - 标题区域失焦后能正确保存标题文字
  - 使用快捷键后不会触发工具栏
  - Ctrl+A 能全选标题区域而非整个 callout 块
  - 标题区域只保留纯文本，不保留富文本样式
- 标题区域粘贴：
  - 粘贴纯文本正常
  - 粘贴带格式文本会正确转为纯文本
  - 粘贴不会破坏 callout 标题结构
- 撤销/重做：
  - 标题文字输入支持撤销/重做
  - 标题文字粘贴支持撤销/重做
  - 标题区域回车新增块支持撤销/重做
- 持久化：
  - 重启页面或关闭再打开页签后仍保持修改后的标题
- 空 callout 行为：
  - 标题区域编辑/粘贴不会使 callout 正文消失

## 2. 折叠/展开功能
- 正常折叠：
  - 点击按钮后能平滑折叠正文区域
  - 箭头同步旋转
  - 正文区域不会突然消失、闪回或出现空白残留
  - 折叠后的 icon / 标题 / 按钮位置正确
- 正常展开：
  - 点击按钮后能平滑展开正文区域
  - 箭头同步旋转
  - 正文区域不会突然出现或闪回
  - 展开完成后新增正文行能继续撑高 callout
- 中途反向点击：
  - 折叠未完成时切换展开，能从当前高度平滑展开
  - 展开未完成时切换折叠，能从当前高度平滑折叠
  - 不会出现按钮状态与正文状态不一致
  - 不会出现正文高度被固定住
- 快速连点折叠/展开按钮：
  - 多次快速点击后最终状态符合最后一次点击
  - 折叠/展开动画符合最后一次点击
  - 不会出现正文高度被固定住
- 撤销/重做：
  - 支持撤销/重做折叠/展开状态
- 持久化：
  - 重启页面或关闭再打开页签后仍保持折叠/展开状态
- 其他：
  - 不会有临时样式/临时属性写进文档
  - 动画中途关闭页面不应造成下一次打开时折叠状态卡死或异常
  - 把 `--callout-fold-duration` 临时改大（例如 1000ms）后，再测是否存在空白、闪现、回弹、裁切、不同步等问题

## 3. 正文输入与编辑
- 正常输入正文：
  - 新增正文块后仍能正常输入
  - 输入时 callout 高度能随正文变化
  - 未折叠状态下不会裁切底部内容
- 正文区域回车：
  - 正文中按 Enter 正常新建块
  - 非尾行空行处回车可新增块并支持撤销/重做
- 正文边界处左右方向键：
  - 光标在正文最左边按 ArrowLeft 时能回到标题
  - 不会丢光标或卡住
- 撤销/重做：
  - 正文区域修改支持撤销/重做
- 持久化：
  - 重启页面或关闭再打开页签后仍保持修改后的正文
- 空 callout 行为：
  - 回车可以删除空 callout，并支持撤销/重做；特别注意嵌套块中的空 callout 行为

## 4. 类型菜单功能
- 打开类型菜单：
  - 点击 icon 能弹出菜单
  - 菜单能尽可能完整显示
  - 菜单失焦后自动关闭
- 鼠标选择类型：
  - 点击菜单项切换类型
  - 切换后的图标 / 背景色 / 标题色跟随变化
  - 切换后不影响正文内容
- 键盘选择类型：
  - ArrowUp / ArrowDown 切换菜单项
  - Home / End 跳到首尾
  - Enter / Tab 确认类型
  - Escape 关闭菜单
- 撤销/重做：
  - 支持撤销/重做切换后的 callout 类型
- 持久化：
  - 重启页面或关闭再打开页签后仍保持切换后的 callout 类型
- 其他：
  - 不会有临时样式/临时属性写进文档

## 5. 补全菜单功能
- 打开补全菜单：
  - 仅引述块首行开头处可输入中括号唤出菜单
  - 支持中文/英文中括号
  - 菜单失焦后自动关闭
- 自动补全：
  - 中括号后输入单个/多个字母时，能筛选相应 callout 类型
- 鼠标选择类型：
  - 点击菜单项选择类型，自动将引述块转为callout
  - 切换后的图标 / 背景色 / 标题色跟随变化
  - 切换后不影响正文内容
- 键盘选择类型：
  - ArrowUp / ArrowDown 切换菜单项
  - Home / End 跳到首尾
  - Enter / Tab 确认类型，自动将引述块转为callout
  - Escape 关闭菜单
- 撤销/重做：
  - 支持撤销引述块
  - 也支持从引述块重做到 callout 块
- 持久化：
  - 重启页面或关闭再打开页签后仍保持选择的 callout 类型
- 其他：
  - 不会有临时样式/临时属性写进文档

## 6. 布局兼容性
- 普通段落中的 callout：
  - callout宽度正常
  - 边框与标题框位置正常
- 列表项中的 callout：
  - 列表中 callout 宽度正常
  - 折叠/展开正常
  - 边框与标题框位置正常
- 水平超级块中的 callout：
  - 在超级块水平布局里不会被拉伸或居中
  - 折叠/展开后宽度与高度符合预期
- 嵌套 callout / 嵌套正文块：
  - callout 内部再嵌套块时折叠稳定
  - 折叠后再展开可恢复正常

## 7. 图片 / PDF / HTML 导出
- 导出的 HTML / PDF / 图片中保持自定义 callout 样式
- 导出结果中不会出现 callout 右上角折叠/展开按钮
- 导出预览中不会出现 callout 右上角折叠/展开按钮
- PDF / 图片预览与最终 PDF / 图片结果中的 callout 表现一致

## 8. 与原生 callout 的切换
- 插件开关能控制原生 callout 与插件 callout 的切换
- 原生 callout 与插件 callout 的折叠/展开状态能被彼此正确识别
- 原生 callout 与插件 callout 的类型能被彼此正确识别（自定义类型除外）

## 9. 稳定性与污染检查
- 折叠/展开、类型切换、标题编辑后，检查 DOM 不残留临时样式
- 不应残留：
  - `height`
  - `overflow`
  - `transition`
  - `will-change`
  - `max-height`
  - `margin-top`
  - `margin-bottom`
  - `flex-shrink`
- 动画中途重载页面，不应出现状态异常
- 重载页面后，callout的类型、标题、折叠/展开等应能保持重载前状态
