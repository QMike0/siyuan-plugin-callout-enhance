> *注意嵌套块中的表现；“callout 正文区域为空且仅一个空行”简称“空 callout”*

## 1. 标题编辑区域
- 标题区域单击：光标定位正确，且不会误触发类型菜单或折叠按钮
- 标题区域回车：
  - callout 展开时：在正文区域首行新增块
  - callout 折叠时：在 callout 块下方新增块，不展开 callout
- 标题区域输入：
  - 中文输入法下输入正常
  - 标题区域失焦后能正确保存标题文字
  - 使用快捷键后不会触发工具栏
  - Ctrl+A 能全选标题区域而非整个 callout 块
  - 标题区域只保留纯文本，不保留富文本样式
- 标题区域粘贴：
  - 粘贴纯文本正常
  - 粘贴带格式文本会正确转为纯文本
  - 粘贴不会破坏 callout 标题结构
- 撤销/重做：
  - 标题文字输入支持撤销/重做
  - 标题文字粘贴支持撤销/重做
  - 标题区域回车新增块支持撤销/重做
- 持久化：
  - 重启页面或关闭再打开页签后仍保持修改后的标题
- 空 callout 行为：
  - 标题区域编辑/粘贴不会使 callout 正文消失

## 2. 折叠/展开功能
- 正常折叠：
  - 点击按钮后能平滑折叠正文区域
  - 箭头同步旋转
  - 正文区域不会突然消失、闪回或出现空白残留
  - 折叠后的 icon / 标题 / 按钮位置正确
- 正常展开：
  - 点击按钮后能平滑展开正文区域
  - 箭头同步旋转
  - 正文区域不会突然出现或闪回
  - 展开完成后新增正文行能继续撑高 callout
- 中途反向点击：
  - 折叠未完成时切换展开，能从当前高度平滑展开
  - 展开未完成时切换折叠，能从当前高度平滑折叠
  - 不会出现按钮状态与正文状态不一致
  - 不会出现正文高度被固定住
- 快速连点折叠/展开按钮：
  - 多次快速点击后最终状态符合最后一次点击
  - 折叠/展开动画符合最后一次点击
  - 不会出现正文高度被固定住
- 撤销/重做：
  - 支持撤销/重做折叠/展开状态
- 持久化：
  - 重启页面或关闭再打开页签后仍保持折叠/展开状态
- 其他：
  - 不会有临时样式/临时属性写进文档
  - 动画中途关闭页面不应造成下一次打开时折叠状态卡死或异常
  - 把 `--callout-fold-duration` 临时改大（例如 1000ms）后，再测是否存在空白、闪现、回弹、裁切、不同步等问题

## 3. 正文输入与编辑
- 正常输入正文：
  - 新增正文块后仍能正常输入
  - 输入时 callout 高度能随正文变化
  - 未折叠状态下不会裁切底部内容
- 正文区域回车：
  - 正文中按 Enter 正常新建块
  - 非尾行空行处回车可新增块并支持撤销/重做
- 正文边界处左右方向键：
  - 光标在正文最左边按 ArrowLeft 时能回到标题
  - 不会丢光标或卡住
- 撤销/重做：
  - 正文区域修改支持撤销/重做
- 持久化：
  - 重启页面或关闭再打开页签后仍保持修改后的正文
- 空 callout 行为：
  - 回车可以删除空 callout，并支持撤销/重做；特别注意嵌套块中的空 callout 行为

## 4. 类型菜单功能
- 打开类型菜单：
  - 点击 icon 能弹出菜单
  - 菜单能尽可能完整显示
  - 菜单失焦后自动关闭
  - 当前 callout 所属类型的设置项文本后存在勾号标记
- 鼠标选择类型：
  - 点击菜单项切换类型
  - 切换后的图标 / 背景色 / 标题色跟随变化
  - 切换后不影响正文内容
- 键盘选择类型：
  - ArrowUp / ArrowDown 切换菜单项
  - Home / End 跳到首尾
  - Enter / Tab 确认类型
  - Escape 关闭菜单
- 启用/禁用类型：
  - 在「设置-Callout 类型」中禁用的类型不出现在类型菜单
  - 已禁用类型的现有 callout 块仍保留样式
- 撤销/重做：
  - 支持撤销/重做切换后的 callout 类型
- 持久化：
  - 重启页面或关闭再打开页签后仍保持切换后的 callout 类型
- 其他：
  - 不会有临时样式/临时属性写进文档

## 5. 补全菜单功能
- 打开补全菜单：
  - 仅引述块首行开头处可输入中括号唤出菜单
  - 支持中文/英文中括号
  - 菜单失焦后自动关闭
- 自动补全：
  - 中括号后输入单个/多个字母时，能按标签与关键词筛选 callout 类型
  - `[`/`【` 后无需输入 `!`，直接输入字母即可触发补全
- 鼠标选择类型：
  - 点击菜单项选择类型，自动将引述块转为 callout
  - 切换后的图标 / 背景色 / 标题色跟随变化
  - 切换后不影响正文内容
- 键盘选择类型：
  - ArrowUp / ArrowDown 切换菜单项
  - Home / End 跳到首尾
  - Enter / Tab 确认类型，自动将引述块转为 callout
  - Escape 关闭菜单
- 启用/禁用类型：
  - 在「设置-Callout 类型」中禁用的类型不出现在补全菜单
  - 历史标签名称不出现在补全菜单
- 撤销/重做：
  - 支持撤销引述块
  - 也支持从引述块重做到 callout 块
- 持久化：
  - 重启页面或关闭再打开页签后仍保持选择的 callout 类型
- 其他：
  - 不会有临时样式/临时属性写进文档

## 6. 布局兼容性
- 普通段落中的 callout：
  - callout 宽度正常
  - 边框与标题框位置正常
- 列表项中的 callout：
  - 列表中 callout 宽度正常
  - 折叠/展开正常
  - 边框与标题框位置正常
- 水平超级块中的 callout：
  - 在超级块水平布局里不会被拉伸或居中
  - 折叠/展开后宽度与高度符合预期
- 嵌套 callout / 嵌套正文块：
  - callout 内部再嵌套块时折叠稳定
  - 折叠后再展开可恢复正常

## 7. 图片 / PDF / HTML 导出
- 导出的 HTML / PDF / 图片中保持自定义 callout 样式
- 导出结果中不会出现 callout 右上角折叠/展开按钮
- 导出预览中不会出现 callout 右上角折叠/展开按钮
- PDF / 图片预览与最终 PDF / 图片结果中的 callout 表现一致

## 8. 与原生 callout 的切换
- 插件开关能控制原生 callout 与插件 callout 的切换
- 原生 callout 与插件 callout 的折叠/展开状态能被彼此正确识别
- 原生 callout 与插件 callout 的类型能被彼此正确识别（自定义类型除外）

## 9. 设置项：Callout 外观自定义
- 打开设置：
  - 左侧导航可切换「外观 / Callout 类型 / 关于」
  - 「外观」页包含外观预设、实时预览与各分组布局字段
- 外观预设：
  - 可在下拉框切换内置 Default 与用户保存的预设
  - 「新增外观预设」可保存当前布局为新预设；名称不可为空、不可与已有预设重名、不可使用保留名 Default
  - 选中非 Default 预设时，「更新外观预设」可覆盖保存当前布局
  - 「删除外观预设」可删除非 Default 预设，删除前需确认
  - 「恢复到已保存预设」在布局有未保存改动时可用，点击后恢复为当前预设已保存内容
  - Default 预设不可更新或删除
- 恢复默认：
  - 「恢复默认」将当前编辑中的布局重置为插件内置默认值，并刷新字段与预览
- 布局字段：
  - 边距与边框、标题、正文、icon、折叠/展开等分组字段可调
  - 修改 slider / 下拉 / 输入后，预览区 callout 实时更新
  - 设置打开期间，编辑器中的 callout 应实时反映外观改动
- 预览区：
  - 点击折叠/展开按钮可预览折叠与展开样式
  - 预览帮助提示说明仅反映默认主题，其他主题需在编辑器中查看
- 关闭设置（外观未保存）：
  - 关闭设置窗口或点击遮罩时，若当前预设布局有未保存改动，应弹出保存/不保存/取消
  - 当前为 Default 且有改动时，保存流程应引导输入新预设名称
  - 选择「不保存」后关闭，编辑器外观应回到关闭前的已保存状态
  - 选择「取消」后应留在设置窗口
- 切换导航：
  - 在外观有未保存改动时，切换到「Callout 类型」或「关于」不应丢失当前编辑中的布局草稿（关闭设置时才提示保存）

## 10. 设置项：Callout 类型管理
- 类型列表：
  - 列表展示各类型预览条、启用开关、编辑与删除按钮
  - 可通过搜索框按标签 / 关键词 / 历史标签筛选
  - 搜索激活时暂不可拖动排序；清空搜索后可拖动条目 reorder，松手后顺序自动保存
  - 无类型或搜索无匹配时显示对应空状态提示
- 新建类型：
  - 点击添加按钮打开编辑弹窗；取消且未确认时不应保留空条目
  - 标签为空时不可保存
  - 标签不可与其他类型的标签、历史标签重复（不区分大小写）
  - 标签不可与墓碑中的已删除标签冲突；冲突时应提示先清理或换名
  - 标签与关键词可互相补全：仅填其一失焦后另一项可自动填入
- 编辑弹窗：
  - 可编辑标签、关键词、主色、icon；非内置类型可查看历史标签（只读）
  - 内置类型 NOTE / IMPORTANT / TIP / WARNING / CAUTION 标签只读，不可删除
  - 主色与 icon 支持「恢复默认」
  - 预览区实时反映编辑内容，支持折叠/展开预览
  - 确认保存后列表更新并提示「设置已保存」；取消不保存改动
- icon 选择器：
  - 点击 icon 按钮打开浮层，可按名称搜索
  - 「全部 / 插件 / 思源」标签页切换可用
  - 选择 icon 后预览与编辑区同步更新
  - 当前 icon 不可用时显示提示，并可「使用默认」
- 启用开关：
  - 关闭后该类型不出现在类型菜单与补全菜单，但已有 callout 块样式不变
  - 切换后立即保存
- 删除类型：
  - 内置类型删除按钮不可用
  - 自定义类型删除前弹窗显示受影响块数量（已打开/已索引笔记本）或未知计数提示
  - 确认后类型从列表移除；对应块回退 NOTE 样式，文档中 subtype 不变
- 墓碑回收：
  - 新建或重命名标签与墓碑中已删除标签冲突时，保存应弹出「回收已删除标签」确认
  - 确认「保存并应用样式」后，相关块应用新类型样式，墓碑记录更新
  - 「返回编辑」应回到编辑弹窗且不保存
- 持久化：
  - 类型列表改动（排序、启用、编辑、删除）关闭设置后仍保留
  - 重启思源后设置仍有效

## 11. 设置项：关于
- 关于信息：
  - 显示版本、作者、仓库链接、许可证链接；链接可正常打开
- 清理历史数据，见「12. 类型重命名 / 删除 / 清理历史数据」
- 调试日志：
  - 「调试日志」开关可即时保存
  - 开启后思源控制台（F12）显示插件详细 DEBUG 日志；关闭后不再输出

## 12. 类型重命名 / 删除 / 清理历史数据
- 重命名（未清理）：
  - 设置中修改 label 并确认后，列表出现 past label；旧 subtype 的块仍显示插件样式
  - 补全菜单不出现 past label 名称；类型菜单写入的是当前 label
- 删除：
  - 删除前弹窗显示「至少 N 个」计数（已打开/已索引笔记本）
  - 确认后类型从列表移除；对应块变为思源默认 callout 样式，subtype 不变
  - 再次新建同名 label 时提示墓碑并可选「保存并应用样式」
- 清理入口（关于 → 清理历史数据）：
  - 只读工作区：点击清理应提示拒绝，不进入流程
  - 编辑器只读：不阻止清理；开始前说明文案可附带编辑器锁定提示
  - 清理进行中「清理」按钮应禁用；结束后恢复可点
- 清理开始前确认（三按钮）：
  - 说明清理会临时打开已关闭笔记本并索引；附带快照说明
  - **创建快照&开始清理**：进入带快照阶段的路径
  - **开始清理**：不创建快照，直接进入迁移
  - **取消**：不启动清理
  - 启动前确认弹窗可通过按钮操作；点遮罩或右上角叉号不应关闭
- 路径一：创建快照&开始清理：
  - 进度弹窗先显示「正在创建数据快照…」（约 0–8%，不确定进度条）
  - 快照成功：进度到 8%、提示可在数据历史中回滚，再进入打开笔记本 / 索引 / 迁移（约 8–100%）
  - 快照失败：关闭进度窗，弹出「创建快照失败」二次确认（无快照是否仍要清理）；**仍要清理** 重新打开进度并迁移（不重试快照）；**取消** 完全退出
  - 快照阶段点进度窗「取消」：仅放弃清理流程（不继续迁移）；设置可恢复操作
  - 快照阶段点设置关闭：「停止清理并关闭」应能停止并关闭设置窗
- 路径二：开始清理（无快照）：
  - 进度从打开笔记本阶段起（约 0–100%，迁移占主要区间）
- 进度与阶段：
  - 阶段：打开笔记本 （→ 创建快照）→ 索引 → 阶段 A（past label → 当前 label）→ 阶段 B（墓碑孤儿 → NOTE）→ 关闭临时笔记本 → 保存设置
  - 阶段 A：合并 past label 对应块的 subtype 与 `[!LABEL]`
  - 阶段 B：无对应类型的墓碑 label 合并为 NOTE
  - 设置窗内未保存的 Callout 类型列表草稿应参与清理（与当前 draft 一致）
- 清理进行中设置限制：
  - 「Callout 类型」页：红色提示「清理进行中…」；搜索、添加、编辑、删除、启用开关、拖动排序均不可用
  - 「外观 / 关于」页仍可切换查看；关于页清理按钮保持禁用
- 清理相关弹窗（进度、快照失败、停止清理、清理期间关闭设置）：
  - 不可通过点击遮罩或右上角叉号关闭，只能点弹窗内按钮
- 关闭笔记本场景：
  - 存在仅关闭笔记本中的旧 subtype 时，清理会临时打开并在正常结束后关闭
- 正常完成：
  - 无 past label、无墓碑（metadata 已清空）
  - 进度窗结束文案为「清理已完成」及处理统计
- 中断清理：
  - 迁移阶段进度窗「取消」：确认「停止清理」后中止
  - 设置窗关闭 / 遮罩 / 叉号：确认「停止清理并关闭」后应停止清理并关闭设置（「留在此页」则继续）
  - 已更新块保持更改；历史标签与墓碑仅在完整成功且写入 metadata 后清除
  - 中止后应关闭为清理临时打开的笔记本
- 索引超时：
  - 某笔记本索引超时时，错误记入清理结果（含笔记本 id 与超时说明）
  - 进度窗结束摘要应出现「历史标签与墓碑记录已保留…」类提示
  - 关闭进度窗后若 metadata 未清空，应再弹「强制清除历史记录」（原因含「部分笔记本索引超时」）
  - 此情况下可能已有块被迁移，但设置里 past/墓碑不会自动清除，需修复后重跑清理或手动强制清除
- 块迁移失败 / 部分失败：
  - 控制台可查看失败块详情
  - 某条 past/墓碑映射若存在失败块，对应 metadata 项可保留；摘要可提示部分保留
  - 关闭进度窗后：有失败或索引超时时可弹「强制清除历史记录」；确认后仅清 metadata，不保证块已全部迁移

## 13. 发布服务：只读 Callout
- 环境：通过思源「发布服务」访问（`window.siyuan.isPublish`），非桌面编辑器内正常编辑
- 外观：
  - callout 样式（颜色、icon、布局变量）应与桌面编辑器中一致
  - 标题行右侧折叠/展开按钮应显示（与编辑器一致，非导出预览那样隐藏）
  - 已折叠 callout 的正文应仍为折叠态
- 只读交互（以下操作均不应改变文档或弹出编辑 UI）：
  - 点击 callout 标题行 icon 区域：不弹出类型菜单
  - 点击 callout 标题文字：不进入标题编辑（不出现可编辑光标/浮动工具栏）
  - 点击标题行右侧折叠/展开按钮区域：不切换折叠/展开状态
- 对照（桌面编辑器同一文档）：
  - icon 可开类型菜单、标题可编辑、折叠钮可切换——确认发布限制未影响正常编辑

## 14. 稳定性与污染检查
- 折叠/展开、类型切换、标题编辑后，检查 DOM 不残留临时样式
- 不应残留：
  - `height`
  - `overflow`
  - `transition`
